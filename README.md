# Anderson Cruz — Portfolio 2026

Redesign moderno do portfólio frontend, mantendo o conteúdo e os projetos originais.

## O que foi atualizado
- Nova identidade visual dark com acentos violeta e ciano
- Hero section responsiva
- Projetos em cards editoriais com screenshots maiores
- Seção Sobre em bento grid
- Navegação desktop e mobile
- Animações de entrada com IntersectionObserver
- Destaque automático da seção ativa no menu
- Botão para copiar e-mail
- Hover states e microinterações
- Melhorias de acessibilidade e SEO básico
- Correção de links quebrados: projetos sem URL pública aparecem como “Em breve”

## Estrutura
- `index.html`
- `style.css`
- `script.js`
- `imagens/`

## Publicar na Vercel
O projeto é estático. Basta importar a pasta/repositório na Vercel e publicar sem framework ou comando de build.
